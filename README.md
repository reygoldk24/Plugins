# Plugins<br>
自分用に手を加えたプラグイン置き場<br>

### ARealmRecorded<br>
　大体なんでも撮れる版<br>
　通常版で撮影できるコンテンツに加えて以下のコンテンツを撮影できるようにした<br>
  <ul>
    <li>PvP</li>
    <li>DD（詩想含む）</li>
    <li>エウレカ</li>
    <li>マスクカーニバル</li>
    <li>クレセントアイル</li>
    <li>闘獣練</li>
  </ul>

### AutoRetainer<br>
　DRを有効にしているとGC納品で停止することがある問題への対応<br>

### DiscordChatBirdge<br>
　ロットに関するログを出力するための記述を追加<br>
